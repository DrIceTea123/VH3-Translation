# 持续规则

归并日期：2026-10-04；最新明确用户要求优先。历史阶段的提交授权不自动延续。

## 协作与文件

- 需求不清或需要决策时先提问并说明原因；新内容放入对应工程。TODO 仅记录，不自动授权执行。
- 仅用户明确要求才提交 Git；保留用户及其他对话的现有改动。
- 安装输入 `translate-packs/`；原始核心、历史公告、表格、旧译文、checker、工具及成品留父工作区。原始输入不改，不记录用户提供的整合包实例路径。
- PowerShell 含方括号路径用 `-LiteralPath`；保留既有脚本编码。OpenLoader ZIP 与当前 VTP 安装 JAR 纳入 Git，其他依赖/构建产物忽略。
- 共享记忆只维护仓库 project-memory。普通轮次追加 note；明确整理时重读并归并，保留历史溯源，不写全局记忆。

## 翻译补丁

- 固定核心、渐进接管，与 VP 共存；运行期不反编译/编译上游，不重建整个核心。
- 默认只改显示边界，保留 ID、存档/网络键、XP 与数值算法。不得让显示中文参与业务查找。客户端 I18n 不进入服务端路径。
- 每个模块各有运行侧和转换侧类；专属处理留在模块，共享 JSON、重载和 ASM 校验。源码适当写中文注释。
- 配置唯一位置 `translate-packs/config/vh3_translation_patch/`，文件名为模块 ID；无源码/JAR 副本，不按语言拆分或覆盖全局语言键。既有模块增删词条只改 JSON。
- mob_names 用真实实体路径，sound_names 用原始 Java 字段；其他默认英文到中文，新特殊输入先确认。牛/首领、未知实体回退及语境差异保留；不猜未确认译名。
- 首次缺失/损坏配置阻止启动，客户端 F3+T 失败保留旧值；缓存界面重开，服务端修改后重启。
- 核心哈希、方法签名/摘要/命中数、内外版本、VP 冲突失败均明确拒绝，不静默绕过。被接管 VP 规则原位留注释，历史规则只作来源/回归输入。

## 版本与导出

- VTP 使用 1.x.x：普通修改修订号 +1；核心更新时小版本与修订号都 +1，修订号不重置。同轮重试不重复加号。
- 每轮 mod 修改后完整验证，导出一个同版 JAR 到 `translate-packs/mods/`，只清理旧 VTP。单包约定取代旧双 JAR 规则。
- 汉化包当前版本 V2.7，维护在 installer.properties；安装器无独立语义版本，export.properties 的正整数序列成功导出 +1，检查/失败不递增。
- 安装器名称模板支持整合包、汉化包版本与序列；模组可取消下载但保留必装标注。跳过 VP 仍删除已知错误版本，保留配置目标文件；不清空 mods。
- 实现、离线测试、加载层探针和游戏验收分别报告。源码/JSON 使用 UTF-8；不强设 Windows JDK 17 Gradle 启动参数文件编码。

模块与 VP 细节见 [Wiki](../wiki/README.md)。彻底移除 VP、特殊位置改用 Mixin、远程发布目标及完整游戏联测安排仍未决定。
