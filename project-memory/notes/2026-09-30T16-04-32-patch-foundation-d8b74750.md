## 已实现

- Gradle Wrapper 8.8（来自 Forge 40.3.11 官方 MDK）、固定 ForgeGradle 6.0.54、JDK 17、Forge 40.3.11；PowerShell build.ps1 选择 JDK 17 并在结束后恢复环境。
- transformer / runtime 两个子项目，分别产生 `vh3_translation_patch-transformer-0.1.0.jar` 与 `vh3_translation_patch-0.1.0.jar`；构建产物位于 `patch-mod/build/distribution/`。
- 早期服务不引用 Minecraft/目标 mod 类型；普通 mod 持有游戏侧辅助类和语言资源，包名边界分离。实查 Forge ModDirTransformerDiscoverer 与 ModsFolderLocator 确认早期服务 JAR 被排除在普通 mod 扫描之外。
- 完整核心 JAR SHA-256、方法名称与描述符、归一化方法摘要、两个返回点数量、重复应用检查、ASM BasicVerifier 校验、转换后 class 导出。
- 目标是 `CombatStatsContainerElement.formatMobName(String)`；保留全部原逻辑，在返回点把完整 ID 与原返回值交给 helper，只影响显示结果。
- helper 按“真实已注册实体 → 专用覆盖 → 实体自身语言键 → 原结果”查找；未知 ID 不误用注册表默认实体，无跨语言/资源重载缓存。
- 启动预检扫描目标 JAR、运行侧配套版本/资源和旧 VP 规则；runtime 入口也检查早期服务已就绪，避免仅安装一半。
- VP 兼容配置生成工具只移除一个已接管的方法规则组，其他规则保留；输出在构建目录，不改写 program/ 中的原配置。
- 从既有 237 条译名导入 235 条带命名空间的 ID 覆盖：213 条 the_vault、22 条原版。`Black Widow Spider` 与 `Mummy` 未确认 ID，保留在导入报告和完整原始词条记录中，没有猜测映射。
- 英文语言文件不放中文专用覆盖；“战斗牛 / 战斗牛首领”差异保留。
- 文档提供构建、配套安装、VP 配置合并与缓存注意事项、回退和验证边界。没有向用户的游戏实例安装文件。
