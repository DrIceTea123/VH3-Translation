## 实现与依据

- 主题词表已有 Andersite Caves、Easter、Raid Vault Orcish 等译文，所有 gen/themes 名称均有配置。缺失来自 VoidCrucibleScreen$ThemeSelect 的 getThemes/initializeViewTheme 使用 NamedKey::getName 方法引用，原 VTP 只覆盖直接调用。
- theme_names 新增两处方法引用的 Function 包装，列表和详情使用现有译表。主题 ID、getter、选择/黑名单逻辑、自定义房间名均保持原值；缓存界面在 F3+T 后需重新打开。
- gear_affixes 新增 EffectTrialAttribute$Reader.getDisplay 和 ModGearAttributes.lambda$static$6(Integer) 两个入口。前者处理完整尾迹组件，保留前缀/效果/时长/颜色及空返回；后者处理凤凰复活说明的动态拼接结果，保留次数和内联颜色标签，由上游继续解析颜色。
- 凤凰 formatter 同时供人类可读文本序列化使用，该文本随之翻译；业务属性、JSON 结构与存档数值不变。移动尾迹的 Generator 仅输出数值范围，不产生漏译句式，保持不变。
- 正式 gear_affixes.json 仅增加三项模板，保留全部现有键值。VP main 的尾迹片段限定 serializeTextElements；VP ulti 仅移出复活两段片段，其他属性翻译不动。历史旧规则追加到 translations/vp/gear_affixes.json，来源清单和基线按已审阅类更新。
- 版本按规则 1.0.16 → 1.0.17；未做 VP 格式升级或无关模块扩展。实现说明见 patch-mod/docs/gear-affixes.md 和 crystal-stats.md。
