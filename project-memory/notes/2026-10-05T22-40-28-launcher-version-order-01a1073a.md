- 日期：2026-10-05 22:40，Asia/Shanghai。

- 状态：源码、文档及 [发布文件] 中三个独立启动脚本已同步修改；未构建、未运行测试或启动脚本、未提交 Git。

Build 移除启动 ZIP 生成、ZIP 权限补写与压缩包发布逻辑，恢复仅输出安装器 JAR，并继续同步三个独立启动脚本。保留 JAR/脚本写入失败回滚及成功后序列递增。BuildTest 随移除的 ZIP 接口调整为现有独立脚本的编码检查，本轮没有执行它。

Windows/macOS/Linux 脚本识别文件名末尾 -V汉化包版本-导出序列号.jar，按数字段比较汉化包版本，版本相等才比较数字序列号。例如 V2.10-1 优先于 V2.9-99；V2.7-18 优先于 V2.7-9。缺失版本段视为零，2.7 与 2.7.0 等价；比较不依赖浮点数或固定整数宽度。整合包版本、修改时间、文件名字典序不决定优先级。

不再显示多 JAR 选择菜单。若最新版本与序列号重复则提示歧义；只有一个文件时兼容改名 JAR；多个文件且没有标准版本后缀时提示无法判定。更新发布目录中的 windows系统点我启动.cmd、macOS系统点我启动.command、Linux系统点我启动.sh；不需要重新编译即可更新脚本逻辑。
