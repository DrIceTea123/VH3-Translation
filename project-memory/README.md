## 读取顺序

新对话依次读本 README、[STATE](STATE.md)、[RULES](RULES.md)、[DECISIONS](DECISIONS.md)、[TODO](TODO.md)，再读下列已归并清单之外的全部 notes，不能按时间猜测。当前技术资料统一从 [Wiki](../wiki/README.md) 进入。

STATE 只写当前事实；RULES 写持续约束；DECISIONS 写选择和理由；TODO 写剩余工作；notes 留逐轮来源与证据。旧 notes 的路径/版本/阶段授权可能已失效。

## 记录与归并

有实质增量新增 `notes/YYYY-MM-DDTHH-mm-ss-主题-唯一后缀.md`，记录 Asia/Shanghai 日期、来源 ID 或需求摘要、类型、状态、决定/事实、验证限制及待办变化。不要编造来源 ID或记录原始实例路径。

普通工作只追加自己的 note；用户要求整理时先重读最新快照和增量，再归并并更新清单，历史 notes 保留。无法读写时明确说明；共享文件不等于聊天全文自动互通。
