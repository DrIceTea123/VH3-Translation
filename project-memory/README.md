## 记录协议

用户已在本项目持续授权记录值得保留的规则、规范、需求与 TODO。每次对话有实质增量时，新建一个简短 Markdown 文件；无需机械记录每次问答。

```markdown
# 简短主题
- 日期：YYYY-MM-DD HH:mm:ss Asia/Shanghai
- 来源：对话 ID；无法取得时写对话主题和用户需求摘要，禁止编造 ID
- 类型：用户规则 / 已接受决策 / 实查事实 / TODO变更 / 建议 / 待验证
- 状态：有效 / 待确认 / 已完成 / 已取代
- 关联：D-xxx、T-xxx 等；新条目可用日期与唯一后缀避免撞号

## 内容
用可独立理解的文字记录新增信息。

## 依据与验证
用户原话或准确摘要；文件位置、版本、检查方式；未验证的部分。

## 后续影响
修改哪些待办或决策；若取代旧结论，明确指出条目和原因。
```

普通写入使用唯一新文件，不覆盖其他对话记录。更新已有 TODO 时在记录中写明原 ID 和新状态；新对话据此解析最新状态，即使 TODO.md 尚未归并也应生效。矛盾的建议不能取代明确的用户决定；最新明确用户纠正优先于旧决定。并发的不同决策无法判断先后时保留冲突并说明。

归并时先重读共享文件，按主题小范围更新快照，保留来源；随后将已归并记录追加到本清单。不要删除历史记录，不要将失败尝试记成完成。大量记录积累后可安排一次独立归并工作，不必每轮全面改写。

## 使用范围与限制

- 在“VH3翻译”本地项目中开始新对话，工作目录应为该工程根目录或其子目录。
- project-memory 不会作为整体自动塞进每个对话；AGENTS.md 要求助手主动读取它。
- 同一目录下的记录是共享的；其他工作目录或未同步文件的电脑不会自动得到它们。
- 没有写下来的聊天内容无法通过此机制保证被记住；中断回合可能来不及保存。
- 既有长对话或同时运行的对话应重新读取记忆后再继续。
- 本协议不授予执行 TODO、自动发布、自动创建新对话或扫描其他项目的权限。
