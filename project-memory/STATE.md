- `sound_names`：声音设置名称，按 ModSounds 原始字段名查表，203 条；未配置时使用原结果。
- 配置仅在 `program/基础+硬编码汉化/config/vh3_translation_patch/`，源码与 JAR 无内置映射。首次缺失/损坏阻止启动；F3+T 错误保留旧值，声音设置需重开。
