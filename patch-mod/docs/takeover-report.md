- 水晶统计接管旧 main/complex/dynamic_2 相关规则；统计数值、分类和 Map 键不变。主题独立处理，显示入口覆盖结算、物品描述和入场悬浮；恢复主题注册表原名以保留内部索引。已对照基线确认注册表除 name 外无变化。
- 房间名称覆盖普通/详细模式及游戏内地图、结算地图共用 formatter。139 个源 ID 包括 dungeon_rooms；显示链没有排除此类 ID，但不能据此声称上游一定将地牢记录到地图。
- 主世界铭文实际数据来源是 gen/templates.json。38 个 ID、46 个键，包含沿用旧译名修正的大小写别名；名称翻译发生在宽度测量前，其他结构与加载状态提示保留原路径。
- 图鉴列表以原始族类 ID 生成查找名称，中文只用于显示，删除旧的中文反查规则；Dweller 特例保留。固定核心只注册 PartialEntityGroup 的前提已经核对。
- 稀有度只接管装备及复用装备稀有度的护符等显示；悬赏、地牢门、宝箱不纳入。未鉴定装备在 RollType.getName 的显示调用结果后翻译，颜色读取、枚举与业务池键不变。旧临时规则已移走，但尚未在游戏中复现并确认旧崩溃根因。
- 两份 Quest 配置的 160 个任务对应 84 个标题；列表、标题及完成通知覆盖。已确认原任务配置文件与基线逐字节一致，未改任务 ID、正文、进度或奖励。
- 特殊词缀采用完整组件句式，包括技能冷却、范围、魔耗、等级、搜刮/受击效果及多种特殊描述；天赋等级使用独立配置避免与技能等级混淆。构造器标题及序列化输出中仍需 VP 的片段被收窄保留。

四个要求的语序示例均通过测试：`火球冷却时间降低10s`、`+1 火球技能等级`、`搜刮华丽宝箱时有10%概率恢复8点魔力`、`+10% 攻击伤害提升`。参数数值及生效样式保留；范围预览保留概率与回复量两个区间。
